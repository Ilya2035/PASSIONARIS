# ORBIS

Великая стратегия на живом 3D-глобусе — в жанре игр Paradox (HoI4, EU5, Victoria 3), но в собственном стиле.
Рабочее название, версия видна в `package.json` и в игре. Правила версий — [docs/VERSIONING.md](docs/VERSIONING.md).

## Запуск

Windows: двойной клик по **`ORBIS.cmd`** — при первом запуске он поставит зависимости, скачает открытые данные
карты (~150 МБ), запечёт карту (~20 с) и откроет лаунчер.

Для разработки:

```bash
npm install
npm run data:download   # один раз
npm run data:bake       # пересобрать карту
npm run dev             # браузер: http://localhost:5173 (лаунчер), /game.html (игра)
npm run build && npm run electron   # настольное приложение
```

## Управление

ЛКМ — тянуть карту · колесо — зум к курсору · WASD/стрелки — движение · 1–4 — режимы карты ·
клик — карточка района · ПКМ — снять выделение · Home — к глобусу · Esc — меню · F11 — полный экран.

## Структура

```
electron/        обёртка: окна лаунчера и игры, настройки, протокол app://
src/launcher/    лаунчер
src/game/        движок глобуса: камера, шейдеры, данные карты, интерфейс
src/shared/      версия, настройки, общий стиль
scripts/         скачивание и запекание карты
docs/            версии, архитектура и планы
data/            источники данных (raw не хранится в git)
```

Источники данных и лицензии — [data/ATTRIBUTION.md](data/ATTRIBUTION.md).
