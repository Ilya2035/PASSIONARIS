# Интерфейс в рабочих цветах (сессия «ui-colors», 11.11.2026)

Для сессий, которые добавляют в альбом или игру новые элементы интерфейса.

- Общая тема теперь подключена и в `album.html`: `src/shared/theme.css` (до `src/album/ui.css`).
- Кнопка: `<button class="btn">` — синяя (действие, навигация); `.ok` зелёная, `.danger` красная,
  `.warn` жёлто-оранжевая, `.off` серая (не выбрано); размеры `.sm`, `.big`, `.icon`.
- Панель: `class="panel"` (+ `.panel-body`), в альбоме `panel pn <место>`.
- Переключатель: `<input type="checkbox" class="toggle">`.
- Цвета только из переменных `--c-*`; текст только `--fs-huge | --fs-l | --fs-m | --fs-s`.
- Никаких градиентов, `clip-path`, фактур: `tests/ui.test.mjs` проверяет `theme.css`, `launcher.css`, `game.css`,
  `legend.css`, `src/album/ui.css`.
- Ручки альбома: `ui.js` строит разделы из `DEFS` (`params.js`). Новая группа появится сама, под своим ключом;
  русское название — в `GROUP_NAMES` в `src/album/ui.js`.
- Перечень элементов для художника — `docs/UI.md`. Новый элемент стоит дописать туда же.
