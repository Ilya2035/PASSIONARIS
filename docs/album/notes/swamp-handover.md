# Болота альбома: что нужно соседним сессиям

Сессия «Болота» (ветка `claude/album-swamp-2a7419`). Полное описание — `docs/album/swamp.md` после выпуска.
Это заметка, не указание: решает ведущая сессия и хозяин каждого файла.

## Сессии ресурсов: болотное железо — закрыто

Решение владельца (11.11.2026, передано сессией ресурсов): железо и болотное железо — одно и то же, отдельного сырья
нет; мелкую добычу у болот люди ведут сами как базовую выработку. С v0.6.20 ресурсы не читают ни `swampIron()`, ни
`album.swamp.ironOf()`, ни `naturalSwamp()`: правило болот и `wetlands.json` можно менять без пересборки таблицы
ресурсов. Ржавый оттенок болот и карта «Болотное железо» остались за частью «Болота» как вид.

Правило, по которому болото ржавое (оно же — готовое место для базовой выработки, если игре понадобится). Чанк
считается железистым, если выполнено всё сразу:

1. болото в чанке не меньше 0,10 (`ch.get('swamp', k) >= .1`);
2. чанк выше досягаемости моря: полная сила с 8 м средней высоты суши, ноль ниже 3 м (приморские марши железа не
   дают: его связывает сера);
3. климат влажный: `wetAt(lat, lon, h)` от 0,58 (полная сила с 0,70); сухие известковые топи (Даймьель, марьяли
   Валенсии) железа не дают;
4. купол верхового торфяника питается только дождём, поэтому там множитель 0,4.

Сила, 0..1:

```
swamp × ss(3, 8, h) × ss(.58, .70, wet) × (1 − 0,6 × доля «верхового торфяника»);   меньше 0,03 считается нулём
```

Функции:

```js
import { swampIron } from './swamp.js';                 // swampIron(swamp, lat, lon, h) → 0..1
album.swamp.ironOf(k);                                  // то же для чанка k; album.swamp появляется в init болот
```

На настоящих высотах и чанках v0.6.20 (с озёрами) это 136 чанков: почти все Ланды Гаскони (там болотную руду
«гарлюш» плавили с железного века до 1892 г.), Галисия, север Португалии, низовья Адура. Страница альбома «Карта
болотного железа» (`page=swamp-map-iron`) показывает их цветом по чанкам.

Чего правило не знает: горных пород. Руда оседает на кислых песках и гранитах, а не на известняке. Когда в игре
появится слой пород, его надо добавить множителем.

## Сессии леса: деревья на болоте

Сейчас `layers/forest.js` редит деревья по числу чанка: `cA.a * .65` против случайного числа. От этого в чанке с
болотом деревья стоят рядами решётки и заходят в воду и на открытую топь. На своих страницах болот вблизи я
выключил объёмные деревья (`forest3d: 0`), чтобы это не мешало смотреть.

Готовое правило лежит в `aspects/swamp.js`: `SWAMP_RULES` (GLSL без uniform и без производных, нужен только `COMMON`).
Замена в вершинном шейдере деревьев:

```glsl
// рядом с ${FOREST_RULES}:  ${SWAMP_RULES}
// вместо cA.a * .65 в строке «no trees on fields and under houses, few in a swamp»:
alive *= step(max(max(cC.g * 1.15, cC.r * 1.6), swampTreeless(cA.a, pk, ll, wet, n2, n3)), hash21(ci + 17.3));
```

`swampTreeless` возвращает долю деревьев, которым здесь стоять нельзя: 0 вне болота, около 1 на открытом торфянике,
тростнике и марше, 0,3–0,9 в заболоченном лесу. Она считает то же поле, что и краска земли, поэтому деревья уйдут
ровно оттуда, где нарисовано болото. Цена: три выборки высоты на дерево, только в чанках с болотом.

## Сессии воды и ведущей: «море» внутри маршей

В низовьях Гвадалквивира в данных высот есть ячейки ниже нуля. Шейдер воды рисует их как море: яркая бирюза и белая
пена прибоя посреди болота (страница `swamp-salt`, середина кадра). Это не моя часть; для болот было бы лучше, если бы
вода ниже нуля вдали от берега рисовалась спокойной лагуной без прибоя.

Ещё одно совпадение формул: чтобы снег не блестел на замёрзших окнах, `aspSwamp` повторяет правило снега из
`terrain.js` (`snow * 1.3 − (n2 * .55 + n3 * .45)` и снеговую линию). Если правило снега поменяется, эту строку в
`swamp.js` надо поменять тоже.
