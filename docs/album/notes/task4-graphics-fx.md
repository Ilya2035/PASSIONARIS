## Что теперь есть в общих файлах

- `src/game/globe.js`
  - текстура шума `uNoise` стала RGBA 512² с мип-уровнями: R и G — прежние случайные байты (`vnoise` читает
    их с уровня 0, результат тот же), B и A — запечённый шум облаков из `src/game/fx/cloudnoise.js`
    (≈80 мс при загрузке);
  - новые униформы шейдера местности: `uDot` (точка «крапинки», её выставляет `fx/events.js`), `uCloudK`,
    `uCloudK2` (готовые пороги облаков от приближения — считаются в `update()` рядом с `uCloudVis`);
  - `uCloudVis` теперь `0.1 + 0.9·zk²` (тела облаков плотнее, поэтому тают раньше).
- `src/game/shaders.js`: блоки облаков и аэрозолей переписаны; режимы 6, 8, 10, 11 берут цвета из
  `src/game/ui/mapcolors.js` (`MAPCOLORS_GLSL`: `KPAL`, `WX_*`, `AIR_*`, `WIND_*`). Палитра Кёппена в
  `src/sim/climate/koppen.js` не тронута, но шейдер и легенда её больше не используют.
- `fx.spawn({type: 'storm', kind: 'tropical'})` рисует циклон с «глазом» (также `subtype`, `tropical: true`).
- `fx.strikes` — времена ударов молний (для снимков: `fx.now = fx.strikes[i] + 0.03`).

## Скорость на встроенной AMD (2560×1600, масштаб 100 %)

Обычный замер «FPS до/после» в разных запусках шумит на ±10 мс, пока работают другие сессии. Надёжно только
парное сравнение в одном процессе: сборка, где старый и новый код шейдера переключаются `#ifdef`, и замер
чередуется каждые ~1,5 с.

Что выяснилось:
- выборка текстуры с орбиты стоит примерно как две дюжины арифметических операций; `sin` / `log` — как
  несколько операций каждая (шесть синусов на пиксель оказались дороже одной выборки);
- `texelFetch` из текстуры шума ради «крапинки» стоил 2–4 мс на кадр — арифметический хэш дешевле в разы;
- динамические ветки по значению из текстуры работают (D3D их не «сплющивает»), если внутри только
  `textureLod` / `texelFetch`: под чистым небом слой облаков стоит одну выборку;
- выражения только из униформ шейдер считает на каждом пикселе — их выгодно считать на CPU.

Итог (мс на кадр, старое → новое): глобус 4,9 → 4,2; экватор с муссоном 4,9 → 2,3; Европа alt 1.0 8,0 → 5,8;
alt 0.35 8,4 → 6,2; alt 0.1 5,5 → 4,4; вплотную 4,7 → 3,6; чистое небо над Сахарой 7,1 → ~0;
пепел издалека 8,7 → 6,9, на среднем удалении 15,0 → 13,4, вблизи 12,7 → 12,8.
