# Living resources: reference numbers (research notes, 2026-11-11)

These numbers are for the stock-based resource map in Passionaris, which starts in 5000 BC.
All units are metric. "Per 100 km²" uses: t/km² × 100; m³/ha × 10 000; runoff mm × 100 000 m³.

How sure each number is:

- **[V]** I read it in the source itself (paper table, report table or dataset).
- **[S]** It comes from a search snippet or a secondary citation; I did not read the original.
- **[D]** I derived it from sourced inputs; the arithmetic is shown.
- **[U]** It is a general reference value or my own judgement; it was not checked this session.

The web search budget ran out near the end, so some rows are proxies. Those rows say so.

## Caveats

1. **Every sea number is a modern, already-fished state.** Ecopath biomasses are balanced models, uncertain by roughly ±50%. Only the North Sea row is an explicit unfished estimate. For 5000 BC, scale them as described under the fish table (total ×2–3, large predators ×5–30).
2. **Proxies.** The Iberian Atlantic shelf, Gulf of Cádiz, Alboran, Tyrrhenian, Pyrenees, Atlantic oak and Mediterranean woodland rows rest on my judgement, not a source checked this session. The relevant open papers are named in each row, so a follow-up session can tighten them. The search budget ran out.
3. **Whales.** The OWID per-species figures are model reconstructions (Christensen 2006), and the "carbon" unit label does not fit the numbers. The Southern Ocean whale total (Laws 1977) is the usual citation but I did not verify it. Biscay right whales and Mediterranean monk seals have **no published pre-exploitation abundance**; their rows are illustrative.
4. **Herbivore values are site measurements, not area averages.** Animals concentrate on the best habitat. A map-wide stock should use the moderate end: about 1 000–2 000 kg/km² for temperate and Mediterranean land, 50–150 for taiga and tundra. The highest savanna, interglacial and Pleistocene numbers include megaherbivores that Iberia lacked by 5000 BC (except aurochs, wisent and horse).
5. **Forest values are timber in standing stems of closed old-growth stands.** A real landscape has gaps, scrub and young stands, so the area-average stock is about 40–70% of the stand value. The redwood and mountain ash figures are world maxima, not typical stands.
6. **Water is a yearly flow, not a stock.** Runoff includes groundwater outflow. Year-to-year variation is large: the short series (1980/81–2017/18) is about 1–10% lower than the long one. Iberian runoff in 5000 BC (wetter mid-Holocene) was probably somewhat higher than today, especially in the south.
