# Заметки сессий второй волны (11–13.11.2026)

Итоговые записки сессий, которые делали части альбома во второй волне. Сессии закрыты; всё, что они сделали, выпущено
до v0.6.45. Записки лежат как были, их не обновляют: это история и справка. Действующие описания частей —
`docs/album/*.md`; чьи файлы сейчас — `docs/ALBUM-CHUNKS.md`.

| Файл | О чём |
|---|---|
| `album-settle.md` | Поселения: свои кварталы, классы и отметки; ночное задание 12.11.2026 (чанк 1 км², район 20 км, настоящие реки и берега, дороги, поля, деревни, сохранение); слова владельца о масштабе 1:1 |
| `album-forest.md` | Лес по чанкам: породы, возраст, зарастание и вырубка |
| `album-water.md` | Вода: море, лёд, озёра, реки |
| `swamp-handover.md` | Болота |
| `division-handover.md`, `division-lands.md` | Деление: районы, провинции, регионы, исторические земли |
| `resources-handover.md`, `resources-research-*.md` | Ресурсы: 52 вида, источники данных, разбор по группам |
| `ui-work-colours.md` | Интерфейс в рабочих цветах |
| `map-coast.md` | Прежняя игра на глобусе: острова и берега на всех масштабах |
| `open-climate-handover.md`, `open-climate-compare.md` | Открытый климат (CHELSA) вместо WorldClim: что скачано и чем отличается |
| `task4-graphics-fx.md`, `task4-report.md` | Первая волна: эффекты движка (затенение, резкость) |

Сырьё, которое скачивали эти сессии, лежит в главной папке проекта и в git не входит: `data/album/osm/`
(OpenStreetMap), `data/album/terrarium/` (высоты), `data/raw/resources/`, `data/raw/climate-open/`.
