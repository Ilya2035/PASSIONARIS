# Моды и дополнения (DLC) Passionaris

Движок открыт для модов с первого дня. Мод и DLC устроены одинаково — это **пакет**: папка с манифестом.
Разница только в поле `kind` (`"mod"` или `"dlc"`) и в том, включён ли пакет по умолчанию.

## Где лежат пакеты

```
public/packs/
  index.json              ← список установленных пакетов: {"packs": ["night-ink", "my-mod"]}
  night-ink/              ← пример мода (выключен по умолчанию)
    pack.json             ← манифест
    main.js               ← необязательный скрипт
```

Страница не умеет сама перечислять папки, поэтому новый пакет нужно дописать в `index.json`.
Игрок включает и выключает пакеты в лаунчере: «Настройки» → «Дополнения и моды». Изменения действуют при
следующем запуске игры; выбор хранится в настройках (`settings.packs = {id: true | false}`).

## Манифест `pack.json`

```json
{
  "id": "night-ink",                 // = имя папки; латиница, цифры, - и _
  "name": "Ночные чернила",
  "version": "1.0.0",
  "kind": "mod",                     // "mod" | "dlc"
  "author": "…",
  "description": "…",
  "enabledByDefault": false,         // у DLC по умолчанию true
  "palettes": { "nightink": { "name": "…", "ui": { "--c-blue": "#3a5fd0" }, "map": { "deep": [0.2, 0.25, 0.34] } } },
  "biomeColors": { "desert": "#e5d3a0" },
  "scripts": ["main.js"]
}
```

Что пакет может добавить данными (без кода):

| Поле | Что делает |
|---|---|
| `palettes` | новые палитры карты; недостающие ключи берутся из «Графита» (`src/shared/palettes.js`). Интерфейс пока в рабочих цветах (`docs/UI.md`): `ui` может переопределить их переменные (`--c-blue` и другие) |
| `biomeColors` | цвета природных зон в режиме «Местность»: `water, ice, tundra, taiga, temperate_forest, steppe, mediterranean, desert, semi_desert, savanna, tropical_forest, wetland, highland` |

## Скрипты

Каждый файл из `scripts` — ES-модуль. Если он экспортирует `install(api)`, игра вызовет её, когда мир
загружен:

```js
export function install(api) {
  // api.version — версия игры; api.pack — {id, name, version}
  // api.hud.toast(html, ms, onClick) — уведомление
  // api.world — системы мира: clock, climate, weather, hazards, regions, fx (эффекты), labels, currents…
  // api.globe, api.scene (three.js), api.gcam (камера: flyTo(lat, lon, alt))
  api.hud.toast(`<b>${api.pack.name}</b> подключён`, 4000);
}
```

Ошибка в пакете не роняет игру: пакет пропускается, предупреждение уходит в консоль.

## Что дальше

Пакеты станут основным способом расширять игру: сценарии и исторические режимы, наборы событий, новые
режимы карты, народы и государства, когда они появятся. Каждое такое расширение получит свой раздел
манифеста. Формат будет версионироваться вместе с игрой (`ЭПОХА.ОБНОВЛЕНИЕ.ШАГ`).
